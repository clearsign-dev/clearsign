# The ClearSign site

A single page, eight sections, no build step. Open `index.html` over any static
server and it runs; there is nothing to compile and no dependency to install.

```sh
python3 -m http.server 8777 --bind 127.0.0.1   # then open http://127.0.0.1:8777
```

## What is here

```
index.html            every section, in order
assets/styles.css     the whole design system, tokens first
assets/app.js         the stage: which section is showing, and everything that switches it
assets/canvas.js      the field behind the page — one fullscreen WebGL shader
assets/fonts.css      IBM Plex, served from here rather than from a font CDN
assets/fonts/         the woff2 files and their licence
assets/*.svg          the mark, generated by brand/make-mark.py
RECONSTRUCTION.md     where the design came from, and what was measured
```

## How the page works

It is a stage rather than a scroll. All eight sections are laid out on top of
one another at the full size of the window, and exactly one carries `.active`.
The wheel, the arrow keys, a swipe, the tick marks down the left edge and the
menu all do the same single thing: change which one that is.

Three consequences worth knowing before editing it:

- **The root font size is `0.9vw` on desktop.** Every measurement in the
  stylesheet is in `rem`, so the whole composition scales with the window rather
  than reflowing at breakpoints. Below 992px the root returns to `100%` and the
  layout becomes ordinary.
- **Sections scroll inside themselves on phones.** A stage exactly one viewport
  tall cannot hold this much text on a small screen. `Stage.atEdge()` in
  `app.js` is what keeps a swipe from skipping to the next section while there
  is still content to read in this one.
- **The menu button has exactly three children.** The rules that fold it into a
  cross address them by position, so a fourth element there silently breaks the
  animation. It has happened once already.

## Accessibility and privacy

There is no analytics, no tag manager, no third-party request of any kind: the
fonts are served from this directory, and the only outbound links are ones a
reader clicks. The contact form opens the reader's own mail client and posts
nothing anywhere.

Section titles are split into individually animated letters for the reveal, and
each one keeps its whole text in `aria-label` with the letters hidden from the
accessibility tree, so a screen reader hears the sentence rather than the
alphabet. `prefers-reduced-motion` turns off the field's animation, the reveals
and every transition. With JavaScript disabled the page falls back to an
ordinary vertical document with everything expanded.
