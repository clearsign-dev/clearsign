## What has NOT been verified

- **Independent re-review is outstanding.** The reported September human review
  predates the subsequent fixes. AI-assisted checks are not a replacement for
  independent human assessment. Do not use development signing tools with real funds.
- **Android is not running as a compartment.** GrapheneOS is verified at source level and its allocator runs in the Linux compartment; building Android needs an x86_64 Linux host.
- **No hardware.** Every result is from software on a general-purpose computer. Side channels, fault injection and physical attacks are untested.
- **The code added on 5 Oct 2026 has had no human review.** The administration, permission and carried-call decoders, the EIP-2930/4844/7702 parsers and the EIP-712 reviewer were written and tested with AI assistance.
- **Long fuzzing campaigns.** Forty-five minutes per target is more than a baseline and still not assurance.
- **The Safe versions checked live are v1.3.0, v1.4.1 and v1.5.0 (and their L2 variants), with v1.1.x on Ethereum.** v1.2.0 shares v1.1.x's domain, which was confirmed from its source, not from a live record. Safe v1.0.0 uses a different struct and is unsupported.
- **Typed data is reviewed, not signed,** and the window does not read it yet.
- **The `bip39` crate's internal word indices are not zeroised.**
