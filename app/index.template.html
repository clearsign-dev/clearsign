Before you sign

clearsign
Runs entirely on this machine. No network, no keys, nothing sent anywhere.

The transaction

Only the fields that are signed are read. Anything else in the file, including the service's own description of the calldata, is ignored.

What it actually does

This is a second opinion, not a secure device. It reads and reports; your hardware wallet still signs. Running it on an everyday computer means trusting that computer. One external security review so far: ten findings, all fixed. The fixes have not been reviewed by anyone outside the project. Never give this a recovery phrase.
